# Will You Be My Valentine?

A beautiful, animated Valentine's Day proposal website for my beautiful girlfriend.

## Features

- Gorgeous dark-themed design with floating hearts background
- Beating heart animation
- The "No" button playfully runs away when hovered
- The "Yes" button triggers a celebration with confetti and hearts
- Fully responsive (works on mobile too)

## How to Use

### Option 1: GitHub Pages (Recommended)

1. Create a new repository on GitHub (e.g., `valentine`)
2. Push this code to the repository
3. Go to **Settings > Pages** and set the source to `main` branch

### Option 2: Open Locally

Just open `index.html` in any web browser.

## Customization

- Edit the message text in `index.html` inside the `<p>` tag
- Change the celebration message inside the `.celebration` div
- Adjust colors by modifying the CSS gradient values
